# Actividad 3: Métodos de Arreglos en JavaScript (Tienda Online)

## Descripción
Este proyecto demuestra el uso avanzado y declarativo de los métodos funcionales de arreglos en JavaScript (`filter`, `sort`, `map`, `reduce`, `find`, `some`, `every`) aplicados a la gestión de catálogo de una tienda online.

---
